# Logic Arrows Launcher v1.0.7 — dark UI polish

## Исправления интерфейса

- Карточки во вкладке **«Карты»** больше не остаются белыми в тёмной теме.
- Названия карт и текст карточки **«Импорт .map»** получили контрастный цвет.
- В настройках блок **«Выйти»** теперь имеет скруглённые края по всему периметру.
- Убраны лишние полоски-разделители между настройками.
- Добавлены единые границы, тени и hover-состояния для карточек карт.

## Игровая сцена

Игровой renderer оставлен полностью штатным. Launcher больше не перехватывает shader или `fetch` игрового grid-слоя: стрелки, их цвета, сигналы, фон и линии клеток одинаково работают в светлой и тёмной теме без подмены Logic Arrows renderer. Тёмная тема применяется только к интерфейсным слоям поверх игры: меню, inventory, toolbar, bind-подсказкам и FPS/TPS HUD.

## Сохранено из v1.0.6

Adaptive TPS governor для больших механизмов, theme dropdown **Системная / Тёмная / Светлая**, импорт `.map` во вкладке **«Карты»** игрового лобби и экспорт из меню открытой карты остаются без изменений.

## Проверка

Пройдены JS bridge syntax, governor/theme smoke и .NET build. Полный визуальный WebView2-тест и проверка цвета клеток на большой реальной карте требуют запуска обновлённого EXE на Windows.
