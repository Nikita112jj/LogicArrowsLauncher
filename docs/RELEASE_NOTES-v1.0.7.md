# Logic Arrows Launcher v1.0.7 — dark UI polish

## Исправления интерфейса

- Карточки во вкладке **«Карты»** больше не остаются белыми в тёмной теме.
- Названия карт и текст карточки **«Импорт .map»** получили контрастный цвет.
- В настройках блок **«Выйти»** теперь имеет скруглённые края по всему периметру.
- Убраны лишние полоски-разделители между настройками.
- Добавлены единые границы, тени и hover-состояния для карточек карт.

## Игровая сцена

Игровые стрелки, их цвета и сигналы остаются штатными. Для тёмной темы Launcher затемняет только официальный `mainRenderTexture` во время `GameRender.clearRenderTextures()`. Grid render texture остаётся штатным бело-серым слоем и применяется штатным multiply-проходом, поэтому сетка видна, а стрелки и энергия не становятся серыми. Shader-ы, `fetch` и ресурсы Logic Arrows не подменяются. Тёмная тема также применяется к интерфейсным слоям поверх игры: меню, inventory, toolbar, bind-подсказкам и FPS/TPS HUD.

## Сохранено из v1.0.6

Adaptive TPS governor для больших механизмов, theme dropdown **Системная / Тёмная / Светлая**, импорт `.map` во вкладке **«Карты»** игрового лобби и экспорт из меню открытой карты остаются без изменений.

## Проверка

Пройдены JS bridge syntax, governor/theme smoke, точечный fake-WebGL shader smoke и .NET publish. Полный визуальный WebView2-тест и проверка цвета клеток на большой реальной карте требуют запуска обновлённого EXE на Windows.
