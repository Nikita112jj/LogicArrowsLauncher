# Logic Arrows Launcher v1.0.7 — dark UI polish

## Исправления интерфейса

- Карточки во вкладке **«Карты»** больше не остаются белыми в тёмной теме.
- Названия карт и текст карточки **«Импорт .map»** получили контрастный цвет.
- В настройках блок **«Выйти»** теперь имеет скруглённые края по всему периметру.
- Убраны лишние полоски-разделители между настройками.
- Добавлены единые границы, тени и hover-состояния для карточек карт.

## Игровая сцена

В тёмной теме белые подложки клеток вокруг стрелок больше не остаются светлыми: изменяется только нулевой цвет подложки в официальных `arrow.frag` и `arrow-chunk.frag`. Поле остаётся тёмным, а линии клеток рисуются белым и остаются видимыми. Красная, синяя и остальные сигнальные цвета остаются штатными.

Игровые стрелки, их цвета и сигналы остаются штатными. Для тёмной темы Launcher затемняет официальный `mainRenderTexture`, а в `grid-generator.frag` оставляет прозрачное поле с белыми линиями. В `arrow.frag` и `arrow-chunk.frag` меняется только нулевой цвет пустой клеточной подложки. `fetch` не перехватывается, signal palette не меняется, поэтому стрелки и энергия не становятся серыми. Тёмная тема также применяется к интерфейсным слоям поверх игры: меню, inventory, toolbar, bind-подсказкам и FPS/TPS HUD.

## Launcher UI

Loading-card и верхняя панель получили единый округлый стиль без лишних рамок. Кнопка **«Играть»** находится сразу под прогрессом подготовки. Кнопка **GitHub** использует официальный Invertocat mark из GitHub Brand Toolkit и открывает репозиторий, а **Changelog** открывает текущий Release v1.0.7. В карточке отображаются понятные статусы, версия и режим self-contained Windows x64.

## Сохранено из v1.0.6

Adaptive TPS governor для больших механизмов, theme dropdown **Системная / Тёмная / Светлая**, импорт `.map` во вкладке **«Карты»** игрового лобби и экспорт из меню открытой карты остаются без изменений.

## Проверка

Пройдены JS bridge syntax, governor/theme smoke, точечный fake-WebGL shader smoke и .NET publish. Полный визуальный WebView2-тест и проверка цвета клеток на большой реальной карте требуют запуска обновлённого EXE на Windows.
