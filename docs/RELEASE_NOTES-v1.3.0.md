# Logic Arrows Launcher v1.3.0 — вкладка Превью, интерактивный визуализатор и умный оптимизатор схем

## Что нового в v1.3.0

- 👁 **Вкладка «Превью и Схемы»**:
  - Быстрый просмотр любого механизма по коду Base64, JSON или файлу `.map`.
  - Интерактивный 2D-холст с тёмной сеткой, зумом колёсиком мыши и панорамированием перетаскиванием.
  - Аутентичное векторное отображение всех типов стрелок, логических элементов (XOR, AND, NOT, Latch, T-FF), детекторов и индикаторов.
  - Подсказка при наведении с координатами `(X, Y)` и названием блока.
- ⚡ **Умный алгоритм оптимизации и сжатия механизмов**:
  - Кнопка **«⚡ Оптимизировать»**: сжимает пустые промежутки между линиями передачи сигналов, убирает дубликаты и смещает механизм в начало координат.
  - Показывает точную статистику сжатия площади (например, `-30%...50% площади`) и позволяет скопировать готовый компактный Base64-код в 1 клик.
- 📁 **Экспорт и интеграция с Проводником**:
  - Кнопка **«💾 Сохранить .map»** для экспорта схемы в файл.
  - Кнопка **«📁 Папка с картами»** для мгновенного перехода в каталог сохранения в Проводнике Windows.
  - Понятная пошаговая инструкция, как импортировать схему в игру.

## Установка

Скачайте готовый `LogicArrowsLauncher.exe` из вложений релиза и запустите на Windows x64.
