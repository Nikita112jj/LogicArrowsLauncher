# Logic Arrows Launcher v1.0.5 — map patch

## Главное

В лаунчере появился собственный формат `.map` для переноса карт Logic Arrows между компьютерами.

## Импорт из лобби

1. Дождись, пока лаунчер закончит подготовку кода.
2. В экране готовности нажми **«Импорт .map»**.
3. Выбери файл в стандартном Проводнике Windows.
4. Нажми **«Играть»** — карта будет передана в официальный runtime Logic Arrows после загрузки страницы.

## Экспорт из настроек карты

1. Открой карту Logic Arrows.
2. Открой штатное меню карты кнопкой в левом верхнем углу или клавишей **Esc**.
3. В окне настроек нажми **«Экспорт .map»**.
4. Выбери место сохранения в стандартном диалоге Windows.

Файл содержит JSON-конверт с данными официального `game.save(map)` в Base64. Лаунчер проверяет формат, версию игры, размер и Base64 и не вызывает облачные map API напрямую.

## Также исправлено

- Повторный вход через «Играть» не перезагружает готовую страницу и не сбрасывает игровые бинды.
- После смены рамки окна фокус возвращается WebView2.
- **Esc** остаётся меню игры, **F1** возвращает в лаунчер, **F11** переключает стандартную Windows-рамку.

## Платформы

Готовый бинарник в этом релизе — Windows x64 self-contained EXE. В репозитории есть папки `linux/` и `mac/` с исходной структурой и планом GUI-порта; фиктивные бинарники для этих платформ не публикуются.
