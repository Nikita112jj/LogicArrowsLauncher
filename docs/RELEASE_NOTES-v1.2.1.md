# Logic Arrows Launcher v1.2.1 — надёжное переименование карт и ссылка на публичную карту

## Что нового в v1.2.1

- ✏️ **Надёжное переименование карт**:
  - Введённое название карты теперь безоговорочно сохраняется в локальную базу IndexedDB (`mapCache`) и API игры при нажатии `Enter` или смене фокуса.
  - Горячие клавиши игры изолированы и не сбивают фокус при наборе текста.
- 🌐 **Прямая ссылка на глобальную карту**:
  - При включении переключателя «Сделать карту публичной» прямо под полем названия карты появляется интерактивная плашка со ссылкой `https://logic-arrows.io/map-<id>`.
  - Клик по ссылке мгновенно копирует её в буфер обмена с подтверждением.

## Установка

Скачайте готовый `LogicArrowsLauncher.exe` из вложений релиза и запустите на Windows x64.
