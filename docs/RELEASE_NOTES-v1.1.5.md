# Logic Arrows Launcher v1.1.5 — исправление переименования карт, импорт Base64-кода и сохранение имён

## Новые возможности и исправления

- ✏️ **Надёжное переименование карт**:
  - Изолирован ввод клавиатуры в текстовых полях интерфейса (`.ui-menu-map-name-input`) и модальных окнах: горячие клавиши игры (пауза пробелом, поворот на `R`, цифры панели инструментов) больше не перехватывают ввод и не сбивают курсор.
  - При нажатии `Enter` или смене фокуса (`blur`) новое название карты мгновенно сохраняется в IndexedDB/базе игры и обновляет заголовок окна.
- 📋 **Прямой импорт Base64-кода карт**:
  - В поле модального окна импорта («Карты» → «Импорт карты») теперь можно напрямую вставить строку кода карты (например, `AAAB...`). Лаунчер мгновенно декодирует её и создаёт мир без лишних запросов к сети.
- 🏷️ **Сохранение названий миров при любом импорте**:
  - При импорте из `.map`-файлов, JSON или из облака по ID/ссылке (например, `map-6ugjRgZm`) оригинальное имя карты автоматически передаётся в созданный мир и сохраняется в игре.

## Установка

Скачайте готовый `LogicArrowsLauncher.exe` из вложений релиза и запустите на Windows x64.
