# Logic Arrows Launcher v1.0.1 patch

## Что исправлено

- **Esc** снова передаётся самой Logic Arrows и открывает меню игры.
- **F1** теперь возвращает из игры в лаунчер.
- Повторный вход через «Играть» больше не вызывает принудительный Reload уже загруженной страницы.
- Перед входом в fullscreen лаунчер ждёт завершения навигации WebView2.
- После смены рамки окна фокус повторно передаётся WebView2, чтобы игровые бинды продолжали работать.
- Добавлены исходные платформенные папки `windows/`, `linux/` и `mac/`.
- README получил выбор платформы, прямую загрузку Windows EXE и ссылки на source для Linux/macOS.

## Управление

| Клавиша | Действие |
|---|---|
| **Esc** | Открыть меню Logic Arrows |
| **F1** | Вернуться в лаунчер |
| **F11** | Показать или скрыть стандартную Windows-рамку окна |
