# Формат `.map`

`Logic Arrows Launcher` использует собственный контейнер `.map` для переноса карт между запусками и компьютерами.

## Контейнер

Файл является UTF-8 JSON с такими полями:

| Поле | Значение |
|---|---|
| `format` | `logic-arrows-map` |
| `formatVersion` | `1` |
| `siteVersion` | `1_4` |
| `exportedAtUtc` | Время экспорта в UTC |
| `mapId` | Идентификатор карты, если его отдала игра |
| `mapName` | Название карты, если его отдала игра |
| `data` | Base64 официального сериализованного содержимого карты |

Поле `data` создаётся внутри официальной страницы Logic Arrows вызовом `game.save(map)` и переводом результата в Base64 через `game.Utils.arrayBufferToBase64`. При импорте лаунчер декодирует Base64 и передаёт байты обратно в официальный `game.load(map, bytes)`.

## Пользовательский сценарий

Нажми **«Играть»**, открой игровое лобби и перейди во вкладку **«Карты»**. Там нажми карточку **«Импорт .map»** рядом с карточкой создания новой карты и выбери файл в Проводнике. Для экспорта открой штатное меню карты в левом верхнем углу или нажми **Esc**, затем выбери **«Экспорт .map»** в нижнем ряду рядом с «Назад в меню».

## Проверки

До передачи в WebView2 лаунчер проверяет имя формата, версию `1_4`, размер JSON, размер Base64 и корректность Base64. Неверные файлы отклоняются. Облачные `/api/map`, `/api/update` и другие маршруты не вызываются напрямую; страница игры остаётся на официальном origin `https://logic-arrows.io`.

## Совместимость

Версия формата сейчас привязана к runtime Logic Arrows `1_4`. Если официальный runtime изменит структуру сериализации, формат будет повышен после отдельной проверки, а старые файлы не будут молча импортироваться как новые.
