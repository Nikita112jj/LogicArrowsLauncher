# Logic Arrows Launcher v1.2.0 — современный чистый дизайн и автообновление с GitHub

## Что нового в v1.2.0

- 🎨 **Полный редизайн интерфейса (No AI Slop)**:
  - Строгое центрирование контента при любых размерах окна и разрешениях экрана.
  - Лаконичный тёмный стиль (в духе GitHub Desktop и Linear) без визуального шума.
  - Тонкий изящный индикатор загрузки с процентами и чётким статусом.
  - Удобная шапка с разделителем, кнопками перехода в репозиторий и список релизов.
  - Крупная кнопка **«ИГРАТЬ»** с приятным откликом.
- ⚡ **Встроенное автоматическое обновление**:
  - Фоновая проверка релизов на GitHub при запуске.
  - Кнопка **«⚡ Обновить»** и плашка при выходе новой версии.
  - Скачивание и перезапуск в один клик.
  - Ручная проверка обновлений в футере карточки.

## Установка

Скачайте готовый `LogicArrowsLauncher.exe` из вложений релиза и запустите на Windows x64.
