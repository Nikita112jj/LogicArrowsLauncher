# Logic Arrows Launcher v1.1.0 — импорт миров по ID/ссылке и модальное окно

## Новые возможности

- **Импорт публичных миров по ID и ссылке**: теперь можно импортировать любые карты, созданные сообществом или открытые для общего доступа, прямо по их идентификатору или ссылке (например, `map-6ugjRgZm`, `6ugjRgZm` или полная ссылка `https://logic-arrows.io/map-6ugjRgZm`).
- **Интерактивное окно импорта**: при нажатии на карточку «Импорт карты» в лобби игры открывается стильное окно с выбором действия:
  - 🌐 **Загрузить по ID / ссылке**: мгновенная загрузка карты из облака через официальный API `/api/mapguest` и открытие её в редакторе.
  - 📁 **Выбрать файл с ПК (.map)**: открытие локального файла `.map` через проводник Windows.
- **Расширенная совместимость форматов**: сервис карт поддерживает как контейнеры `.map`, так и прямые JSON-выгрузки API игры.

## Рендеринг и исправления

- Полностью сохранена и проверена плавная работа сигналов в тёмной теме без задержек и застываний.
- Серая сетка поля непрерывно видна под стрелками и между ними на любых уровнях масштабирования.
- Сохранена полная совместимость с Windows x64, автономный запуск без необходимости установки .NET Runtime.

## Установка

Скачайте готовый `LogicArrowsLauncher.exe` из вложений релиза и запустите.
